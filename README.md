# Secure Login System

Secure Login System with hashed passwords, SQL injection protection, session management and logout.

## Features
- Register / Login with bcrypt hashed password (plain password store panna matom)
- SQL Injection protection using parameterized queries `?`
- Session management with Flask session
- Logout - session clear pannidum
- SQLite Database

## How to run
pip install -r requirements.txt
python app.py

Open browser la: http://127.0.0.1:5000/register
